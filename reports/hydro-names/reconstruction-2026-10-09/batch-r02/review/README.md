## Offline validation

From this directory, `python validate-independent-review.py` checks the durable
public package alone. It checks frozen input hashes, full selected geometry shapes
and ordered coordinates, public evidence pins and review/application gates. It
**does not** claim to re-read raw sources or re-decode unavailable binary assets.

Optional arguments `--input-cache`, `--historical-input-root` and
`--local-source-index` enable the corresponding complete-input checks. With all
three, the validator also independently parses the binary index and selected
varint geometry packs, replays the pinned production decoder, checks the selected
historical inventory joins and hashes thirteen locally retained source bodies.
The private source index maps each public `original_id` to a `local_path`; it is
not part of this package.

`test-independent-review.py` uses disposable copies and the same three local-input
arguments. It confirms rejection of modified geometry or original-source bytes,
an invented Korean name, removal of the reservoir water-mask hold and replacement
of Buffalo by the rejected Tathlina lead.

The validation report records which mode actually ran. Hashes protect the frozen
observations; they cannot independently reproduce human interpretation of maps.
No network access is used. A current live deployment was not checked.

## Publication boundary

Only original factual observations, validation code and metadata are included.
Raw articles, PDFs, map scans and derivative crops stay outside this directory.
Selected Natural Earth geometry rights are documented in the parent package.
