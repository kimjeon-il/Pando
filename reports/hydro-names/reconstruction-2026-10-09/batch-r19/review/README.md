## Source assessment

The original Bureau of Meteorology [Australian Water Resources Assessment 2012](https://www.bom.gov.au/water/awra/2012/documents/assessment-lr.pdf), published in 2013, was inspected. Figures 3.1, 3.22, 3.61, 15.1 and 15.22 contain relevant channel and regional context. Physical PDF pages are 48, 69, 108, 681 and 703. Direct channel lettering was distinguished from catchment titles, irrigation shading, and other thematic layers. These views and the supporting prose are one publication, not independent corroborating sources. No new external source request was needed.

The full selected groups were privately inspected and every selected baseline fragment and its metadata were independently decoded. This is regional visual correspondence, not a numerical map registration, exact topology check, naming-register decision or surveyed modern mouth.

## Public evidence boundary

The eight files in this component contain own factual observations, bibliography, summary linkage, included-file hashes and bounded tests. They do not contain original map bodies, full river paths, omitted-input fingerprints, or an interface for replaying private inputs.

Run Python with -B on validate-independent-review.py or test-independent-review.py. Both operate only on included public package files. The tests cover public integrity, target/summary joins, source distinctions, preserved naming limits, and mutation rejection. They explicitly cannot reproduce omitted original map interpretation, full-path inspection or private original-decoder judgments. A passing public test is not new empirical confirmation of the names.
