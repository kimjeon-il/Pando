## Public validation boundary

These eight review-component files contain factual observations, bibliography, bounded summary linkage, tests and hashes of included files only. Original maps, full river paths, omitted-input fingerprints and private replay interfaces are not included. The ten included geometry-component files are the sole external component dependency. No separate source module is required.

Run `python -B review/validate-independent-review.py` and `python -B review/test-independent-review.py` from the package directory. The validator checks included-file integrity, selected summary joins, source distinctions, naming limits and current-delta continuity. The tests exercise a finite set of public-record mutations and included-byte integrity. They cannot reproduce the omitted original-map interpretation, full-path inspection or original-decoder judgments. A passing public check is not new empirical confirmation of the names.
