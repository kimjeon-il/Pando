## 대상과 기준일

승인된 [공통 지도·열람 구조 정리 계획](../../../docs/superpowers/plans/2026-10-19-shared-viewing-cleanup.md)을 구현했다. UI 재설계, 분포도 동작, 프로젝트 파일 형식, C++ 문서 모델, 네이티브 편집 내부는 변경하지 않았다. 별도 육지 배경은 프로젝트 문서에 저장하지 않는다.

이 문서는 [해안 점선 재발 조사](child-coast-recurrence-audit-2026-10-19.md)와 [빈 시점 육지 소실 조사](empty-time-land-mask-2026-10-19.md)의 구현 후속이다. 기존 사용자 탭의 실제 캐시 내용은 확보하지 못했다. Worker 버전 혼합 실험의 재현을 그 탭의 원인 확정으로 확대하지 않는다.

## 근거와 방법

기존 공통 계산·렌더링·자산 수집 소유자를 수정했다. Worker 자산은 공식 `generate-build-metadata.mjs`가 생성하고, 웹의 `collectViewerAssets` 및 앱 staging이 같은 생성 목록을 소비한다. classic/module 구분과 초기화 순서는 유지하며, 실행 모듈은 의존성 전체가 포함된 내용 해시 디렉터리에 둔다. 해시에는 원본과 패키저 코드가 포함된다. classic importScripts는 각 인자를 검사하고 고정 목록 밖의 계산된 실행 경로를 거절한다. 부트스트랩 메타데이터는 해시 순환을 피하도록 원래 위치에 revision 쿼리를 유지해 참조하며, 자료와 검증된 WASM도 원래 소유 위치를 사용한다. 양쪽 staging은 생성물 `--check`를 선행한다.

물리 육지 원본은 기존 지형 제작에 사용한 `countries-ne-5.1.1.geojson`이다. 원본 좌표를 변경·단순화하지 않고 정치 속성 없이 하나의 MultiPolygon으로 포장했다. 원본 SHA가 지형 manifest의 landMaskSha256과 일치하는지 생성 단계에서 검사한다. 역사 경계 재구성이나 독립적인 시대별 형상의 0.5 CSS px 정확도 검증은 수행하지 않았다.

브라우저 검사는 1280×800 또는 1440×900에서 실제 내장 자료 및 현재 형식 `.gpkg`를 사용한다. Canvas를 강제한 Chromium과 WebGL2 SwiftShader를 구분한다. 픽셀·Worker 응답·메시지 수 계측은 테스트 응답에만 삽입하며 제품에 별도 디버그 소유자를 추가하지 않는다.

## 확인 결과와 한계

| 책임 | 정리 결과 |
| --- | --- |
| 경계 | `country-shared-boundary-packet.js`가 일반 객체의 접촉·내부·외곽을 결정한다. 지형 모드의 해안 정책을 상위·하위에 동일하게 적용하고 마지막 선 스타일만 구분한다. 지역 객체의 독립 경계 경로는 유지한다. |
| 출력 | 일반 하위 객체를 territorial 경계 도메인에서 중복 출력하던 경로와 native 국가 선 출력 경로를 제거했다. Canvas/WebGL은 같은 공통 경계 배치를 소비한다. 기존 모드 정책에 따라 색채 지형에서는 해안을 제외하고, 흑백·지형 없음에서는 외곽을 포함한다. 이 정책 자체를 계층별로 나누지 않는다. |
| 육지 | `physical-resources.js`가 자료 revision에 고정된 마스크를 소유하고 두 렌더러가 같은 `physical-land` 패킷을 소비한다. 정치 객체 시점·숨김·색상으로 육지 마스크를 만들지 않는다. |
| 보기 복원 | `ProjectSession`이 저장한 layerPresentation을 현재 정규화 경로로 복원한다. opacity 0.25 저장→초기화→복원 및 문서·dirty·이력 불변을 검사했다. |
| 검색·선택 | `ObjectQuery`의 현재 존재·표시·자료 판정을 검색과 선택이 공유한다. 검색은 전체 자료의 현재 표시 대상이며 화면 범위와 라벨 충돌로 제한하지 않는다. |
| 내장 지명 | `placeLabelRowsAtMonth`를 화면·Worker 검색·선택/호버 정보가 공유한다. 1990년 키예프와 현대 키이우를 구분하며, 이름 근거가 없는 기간에 존속기간을 추정하지 않는다. |
| 상태 | 시점과 보기 변경 후 공통 조회의 객체 수를 갱신한다. Core epoch는 읽기 투영 갱신에도 증가하므로 문서 revision/dirty/Undo 및 문서 스냅샷과 별도로 취급한다. |

삭제한 이전 경로: 국가 선 전용 셰이더·VAO·인덱스 버퍼 업로드, 정치 mesh 기반 육지 마스크 셰이더, mesh outline exclusion fallback, 일반 하위 객체의 별도 territorial 선 출력, 검색 폴더/트리 모델·확장 상태·정규화·GIS 전달 포트 및 해당 구형 테스트. 기존 mesh 파일의 lineIndices 데이터 계약과 실제 사용하는 수계·편집 선 출력은 유지했다.

단위 검증: 경계·Worker·물리 배경·프로젝트·검색·보기·지명·GIS 표시·staging 관련 160개와 추가 Pages staging 6개가 통과했다. 평면 검색의 순환 부모 항목도 폴더 상태 없이 검색됨을 확인했다. 선택한 변경 JS의 ESLint 및 버전 검사는 통과했다. 전체 스위트는 실행하지 않았다.

별도로 실행한 기존 전체 소유자 조립 검사는 `propertySelection.workspaceUiA` 포트의 12개 제한을 초과하는 기존 구조를 검출했다. 그 포트의 13개 멤버는 기준 커밋에도 존재한다. 이 작업에서 제한을 완화하거나 관계없는 편집 UI 포트를 재설계하지 않았다. 소유자 탐색기가 일반 resourceCapabilities 함수를 생성자로 잘못 수집하던 부분은 실제 create 함수만 수집하도록 수정했다.

Canvas 고유 색상 왕복의 최종 측정 프레임은 색채 3.6–6.9ms, 흑백 3.0–6.3ms였다. 양쪽에서 지형 캐시를 재사용했고 `replace-data` 횟수는 증가하지 않았다. 이 수치는 해당 로컬 장비·브라우저의 프레임 측정이며 모든 장치의 시작 시간 보장이 아니다.

## 최종 검증 기록

- 앱 WebGL2: 실제 `.gpkg` 열기→홍콩 검색→이동·확대 흐름 및 공통 경계 소유 검사 통과.
- 앱 편집 시작점: 임시 보기·시점 조작 뒤 문서와 저장 결과 불변, 수계·지명 지연 로딩 검사 통과.
- 앱 staging: small-project 1,121파일/62,454,473바이트, full-world 1,719파일/154,471,193바이트의 로컬 검사 통과. 후속 자산 변경 시 재생성 결과를 최종 기록으로 사용한다.
- 별도 검토에서 찾은 GPU 업로드 로컬 할당 누락, 지명 선택 표시의 현대 이름 사용, 초기 데이터 Worker의 메타데이터/자료 URL 재배치 누락을 수정하고 관련 검사로 재확인했다. 혼합 importScripts 인자에서 동적 의존성이 검사를 통과하던 마지막 지적도 AST 인자별 검사로 수정했다. 실패 재현 후 Worker 6개 검사 및 별도 재검토가 통과했으며, 현재 남은 검토 지적은 없다.
- Canvas DEM 및 WebGL2 로컬 raster: 홍콩의 시점 왕복·객체 표시 OFF·흑백 전환·평면 전환에서 육지를 유지했다. Canvas 색채 픽셀은 왕복 모두 `[124,170,150,255]`, WebGL은 `[128,174,153,255]`였다. 문서 스냅샷과 revision/dirty/Undo 상태도 동일했다.
- 옛 버전 없는 계산 URL을 실패시키는 제어 조건에서도 현재 해시 Worker로 실행했으며 그 옛 URL 요청은 0회였다. raw Worker 시작 파일은 웹 목록에서 제외한다.
- 수계 Worker의 bare sibling importScripts 의존성 누락도 수정했다. 알 수 없는 계산 스크립트 의존성은 생성에 실패하며 관련 Worker 검사 6개가 통과했다.
- 웹 staging: 자산 커밋 `f29bd5f8cd00ed1cfbf4d7e370285293ec8b9ca6`의 1,398파일/113,970,346바이트를 커밋된 바이트로 조립하고 해시를 확인했다. 편집 진입점과 버전 없는 Worker 시작 파일은 0개다. 그 조립본을 별도 로컬 서버에서 실행한 Canvas DEM의 시점 왕복·표시 OFF·흑백·평면·문서 불변 검사도 통과했다. 공개 게시를 수행한 것은 아니다.

## 데이터 반영과 미검증

역사 GIS 형상을 수정하지 않았다. 원본과 좌표의 보존은 생성·단위 검사로 확인했으며 새 역사 정확도를 주장하지 않는다.

Windows 네이티브 WebView, Android 실기기 및 네이티브 회전, 기존 사용자가 열어 둔 탭의 실제 캐시 바이트는 이 변경본에서 미검증이다. 로컬 editor HTML 검사와 staging 결과를 네이티브 실행 증거로 간주하지 않는다. 이번 변경의 main 통합·원격 게시·공개 배포 SHA 및 실제 공개 자산 대조는 아직 수행하지 않았다.

검증 수치와 배포물 manifest 해시는 [기계 판독 근거](shared-viewing-cleanup-2026-10-19.evidence.json)에 기록했다.

## 판본

이 보고서가 위 두 원인 조사의 구현 후속이며, 기존 배포 보고서의 과거 검증 상태를 변경하지 않는다. 이후 게시 시 배포 커밋 SHA·실제 제공 자산·기존 캐시 조건의 결과를 별도 기록해야 한다.
