# 일반객체·지방객체 통합의 과거 단계별 진행 기록

> 작성 당시: 2026-10-03 · 과거 실행 기록 · 현재 빌드/검증 상태와 별개

- 원래 SDD에서는 일반·지방객체의 계층/ID/Store/Repository 전환을 단계별로 수행했으며 초기 단계3 중간 상태는 배포 불가로 분류했다.
- 2026-10-04 작성 당시 단계 6에서 객체 UI·GIS 소유국/종류 계약과 중복 코드 정리를 완료했다고 보고했지만, **Python 역사 자료 생성기의 전체 재생성·결정성 검사**는 pyproj 부재로 수행하지 못했다.
- 현재 설계 정본은 [TerritorialEntity 계약](../../../docs/architecture/territorial-entity-contract.md) 및 [축약된 구현 계획](../../../docs/superpowers/plans/2026-10-03-unified-objects.md)이며, 구 SDD의 완료·미완료 문구는 당시 체크포인트에 한정한다.

[정리 전 원문·전체 테스트 목록·출처·원본 커밋](https://github.com/kimjeon-il/Pando/blob/6b0c501dd09029ef237e90c1ef55fdb82bdf315f/reports/development/testing/unified-objects-sdd-progress.md)을 참조할 것. 현재 지도 데이터·런타임 변경이나 검증 완료를 의미하지 않는다.
