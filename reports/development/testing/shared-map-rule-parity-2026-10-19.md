## 대상과 기준

객체 호버의 깃발 누락, 하위 객체 경계, 웹 조립부의 독자 규칙을 재점검했다. 상설 `work/ui`의 별도 프로젝트 설정·시점 비교·Core/WASM 작업은 보존하고 배포에서 제외한다. GIS 원본·형상·역사 자료는 수정하지 않았다.

## 확인 결과와 수정

| 항목 | 확인한 차이와 현재 소유자 |
| --- | --- |
| 호버 깃발 | 공통 `ObjectQuery.objectDisplayInfo`에 깃발이 없었다. `effectiveTerritorialFlagUrl`을 연결하고 앱의 별도 호버용 조립을 제거했다. 기본 국기·직접 지정 깃발·깃발 없음 규칙을 공유한다. |
| 일반 하위 경계 | 같은 GPKG에서 웹·앱이 같은 Worker와 경계 패킷을 사용했다. 하위 경계의 점선·두께·불투명도 차이는 재현되지 않았다. 독립 권역도 비교했다. |
| 호버·선택 외곽선 | 웹이 `countryOutlineFeature`를 원본 반환 함수로 대체했다. 앱은 `TerritorialLabels`의 `MultiLineString` 변환을 사용했다. 웹의 두 우회를 제거하고 실제 공통 소유자를 연결했다. |
| 숨긴 객체 | 웹은 존재 여부만으로 선택 표시를 허용했다. 앱의 실제 표시 여부 함수를 `ObjectQuery.objectRefVisible`로 옮겨 양쪽이 사용한다. 수계 숨김 ID 처리도 유지했다. |
| 호버 응답·클릭 | 웹의 직접 호버 변경과 교체 중 여부만 확인하는 클릭 판정을 제거했다. `GpuScene.setMapHover`, `PointerTargets.mapClickBlocked`의 세대·이동·클릭 억제 검사를 공유한다. |
| Worker 완료 | 제품별 경계·강조 계산 완료 후 갱신을 `RenderingDomain`으로 옮겼다. 앱의 존재하지 않는 선택 갱신 메서드 참조도 실제 `invalidateSelection`으로 바꿨다. |
| 기타 조립 규칙 | 두 좌표 유효성 검사, 분포 항목 필터, 항상 거짓이던 오류 메시지 판정을 `CountryIndex`, `distributionEntriesForLayer`, 공통 알림 소유자에 연결했다. 수계 그룹·경계 레이어·선택 경계 분할·경계 revision·라벨 참조 포트도 연결했다. 사용하지 않는 웹 `fit`과 인수를 제거했다. |

## 재점검 범위와 구분

`viewer-map`, `viewer-composition`의 조회·가시성·색상·라벨·투영·입력·렌더 자원 연결을 앱 조립부 및 실제 피호출 소유자와 대조했다. 색상 상속·경계 위상·분포·일반 객체·수계·라벨 배치·카메라·품질 계산은 기존 공통 소유자를 사용한다. 테마나 상태를 전달하는 포트 바인딩은 남지만 새 정책 구현을 만들지 않았다.

웹 표시 변경은 세션의 열람 상태를 바꾸고 앱은 문서 명령을 실행한다. 편집 도구·초안·이력·저장·자동저장 등록, HTML 출력과 배포 목록은 제품 역할에 따라 다르다.

초기 preview 선택은 웹의 저장 문서 기반 시작과 앱의 내장 preview 시작 사이에 차이가 남는다. 앱도 저장 프로젝트를 시작할 때는 preview를 사용하지 않는다. 이 경로는 이번에 변경하지 않았고 전체 시작 시간·메모리·성능이 같다고 주장하지 않는다. 저장소 전체 모든 동작의 동등성 증명으로도 확대하지 않는다.

## 근거와 검증

- 현재 Core/WASM writer로 부모·자식·독립 영토·독립 권역, 직접 지정 깃발, 분포, 일반 선 객체가 있는 GPKG를 만들고 두 제품의 실제 파일 메뉴로 열었다.
- 실제 공통 렌더러의 geometry/style/order 패킷과 외곽선을 비교했다. 알고리즘을 테스트에 복사하지 않았다. 부모·자식의 실제 지도 포인터 호버와 깃발, 호버 전후 문서 불변도 검사한다.
- 깃발 누락, 표시 여부 함수 부재, `Polygon`/`MultiLineString` 차이, Worker 완료 후 갱신 누락은 수정 전 실패를 확인했다. 합성 형상·비정규 UUID·분포와 겹친 포인터 지점의 테스트 준비 오류는 제품 결함으로 집계하지 않았다.
- 관련 단위 검사 109/109, 최종 선택·포트·경계 검사 72/72 및 변경 파일 ESLint 통과. 중복 실행을 독립 검사 수로 합산하지 않는다. 앱 속성·계층·깃발 검증 및 Undo/Redo 브라우저 검사 통과. 제품 HTML·배포 의존성·실제 capability·개별 표시 명령 검사 17/17 통과. 개별 표시 테스트의 persistence 대역에 현재 필수 해제 메서드가 없어 teardown이 실패하던 부분은 대역을 갱신해 재검사했다.
- 원시 로그: 상설 UI 워크트리 `.superpowers/sdd/shared-output-parity-20261019/`. 검증은 별도 수정본 export와 커밋된 기준 WASM에서 수행했다.

## 미검증 및 배포

최종 실제 포인터·깃발·문서 불변·부모/자식/권역 경계·분포·일반 객체 비교 1/1 통과. 배포 증거는 완료 후 추가한다. 이번 후속 수정에서 Windows·Android 네이티브 패키지를 빌드하거나 실기기에서 실행하지 않았다. 브라우저 앱 검사를 네이티브 검증으로 표시하지 않는다. 기존 배포 지시에 따라 검증 후 웹을 게시하며 push·workflow·공개 응답·실제 호버를 구분한다.
