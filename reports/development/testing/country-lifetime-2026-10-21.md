## 대상과 원인

기본 세계 프로젝트의 국가 존속기간이 지도 자료의 기준월인 `2026-10`로 제한되어 정보창에 표시됐다. 생성기는 국가 원본 수명과 지도 제공 구간의 교집합을 프로젝트 수명으로 저장했고, C++ 검증기도 수명 전체에 경계·부모 기록이 있어야 한다고 요구했다. 기존 역사 지도 연결 사양도 이 의미를 명시했으므로 생성기와 공통 모델 계약을 함께 수정했다.

## 수정과 판단

- 프로젝트 `lifetimes`를 국가 원본 수명에서 생성하며 연·월·일 정밀도와 빈 끝점을 보존한다. 입력에 날짜가 없으면 현재 날짜로 채우지 않는다.
- 경계와 부모 관계는 동일한 구간에 함께 존재해야 한다. 수명 안에서 둘 다 없는 자료 공백은 허용하며 지도에서는 숨긴다. 중복·수명 밖 기록·부모 자료 공백·순환 관계 검사는 유지한다.
- 경계 자료 구간과 실제 수명을 서로 대신 읽던 하위 객체 생성 경로를 수정했다. 연속하는 경계 버전들을 하나의 제공 구간으로 계산하며 정확한 날짜 시작도 보존한다.
- **판단:** 명시적 삭제가 마지막 지도 구간을 없애면 기존 삭제 동작과 같이 프로젝트 객체와 남은 기록을 정리한다. 표시할 경계가 전혀 없는 불완전한 투영 객체를 새로 도입하지 않는다. 원본 라이브러리는 그대로 보존한다. 이 판단의 비용은 자료가 전혀 남지 않은 삭제 객체의 과거 수명도 프로젝트에서 제거된다는 점이다. Undo로 복원된다.
- **판단:** 기존 제품의 존속기간 직접 편집 거부(`TIMELINE_ACTIVATION`)는 유지한다. 새 기간 편집 기능은 추가하지 않으며 다른 속성 편집의 Undo/Redo와 저장·복원에서 원본 수명이 유지되는지 검사한다.
- 관련 테스트의 이전 records schema와 baseline 활성화 호출을 현재 계약으로 갱신했다. 프로젝트 형식 호환 코드나 이전 API 별칭은 추가하지 않았다.
