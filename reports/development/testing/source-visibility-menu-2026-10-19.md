# 보기 메뉴의 내장 자료 구분 제거

> 보고서 ID: `UI-SOURCE-VISIBILITY-20261019` · 상태: `focused-verified / unpublished / native-unverified` · 지도 반영: `not-applicable` · 색인일: 2026-10-19
> 원문 최종 수정: 2026-10-19
> 조사 기준: 웹·앱 `f48aa4028a3e5165efafc086e3aa0da03ff5e1d0` 및 `work/ui` 미커밋 수정본
> 원본·출처: 사용자 메뉴 화면과 요청, 공통 보기 fragment·설정·검색·자료 로더

## 대상과 기준

사용자 요청에 따라 보기 메뉴 상단의 `내장 강·호수`, `내장 지명` 두 항목을 제거했다. 아래 지명·강·호수 표시 설정은 자료 출처를 구분하지 않는다. 나머지 메뉴 항목은 유지했다. 기존 하위 객체 해안 경계 수정과 다른 미커밋 작업은 보존했다.

## 수정과 공통 소유자

- 공통 `ui/fragments/map-display.html`에서 두 항목을 삭제하고 웹·앱 HTML을 공식 생성기로 재생성했다. 웹의 경위선·지구본 그림자와 앱의 고급 보기 항목은 유지했다.
- 사용자 환경설정의 별도 내장 표시 키와 검색·수계·지명 렌더링·Canvas Worker의 해당 표시 분기를 제거했다. 과거 환경설정의 내장 숨김 값은 정규화 결과에 남지 않는다. 프로젝트 데이터·저장 형식은 변경하지 않았다.
- 지원 자료 유무를 나타내는 제품별 불변 capability는 유지했다. 작은 프로젝트 배포물에 없는 자원을 요청하거나 검색에 노출하지 않는다. 이것은 사용자 표시 설정과 별개인 배포 계약이다.
- 앱 시작 시 수계·지명을 미리 읽지 않는 기존 동작은 유지했다. 아래 강·호수·지명 표시를 켜면 기존 자료 로더를 호출하며, 이후 지명 화면 이동 갱신도 기존 runtime이 담당한다. 새 로더·별도 표시 상태는 추가하지 않았다.

## 검증과 한계

- 단위 검사 41/41 통과: `product-html`, `user-preferences`, `viewing-visibility`, `editor-resource-capabilities`, `object-search-controller`, `map-label-visibility`, `core-hydro-copy-history-wasm`.
- 앱 편집 시작점 브라우저 검사 1/1 통과: `editor-focus-storage.spec.mjs`의 `temporary viewing` 흐름. 두 메뉴 부재, 시작 시 자료 요청 없음, 아래 강·지명 표시를 껐다 켰을 때 지연 로딩, 지형 요청 없음, 문서·저장 범위 불변을 확인했다.
- 변경 JS·검사 ESLint와 빌드 메타데이터/생성 HTML 일치 검사 통과. 배포용 새 빌드 번호는 발급하지 않았다.
- Windows·Android 네이티브 앱 재빌드·실행, `main` 통합·커밋·push·Pages 배포는 수행하지 않았다. 브라우저의 앱 시작점 검사를 네이티브 실행 증거로 취급하지 않는다.

## 별도 홍콩 지형 채색 조사

사용자가 제보한 흑백 지형의 홍콩 무채색 현상도 조사했다. 공통 재질 해석에서는 홍콩이 CHN의 `#cc3333`을 상속하고 흑백 모드 alpha 0.68, 색채 모드 0.22, 지형 없음 1로 계산됐다. 공개 Edge에서 평면 전환·중국 검색의 이동 버튼·홍콩 확대·선택 해제·색채에서 흑백 전환을 실행한 현재 화면에서는 홍콩이 채색됐다. 이는 해당 조건에서의 비재현 관찰이며 원인 해결 증거가 아니다.

자동 화면 탐색 중 검색의 선택 버튼을 이동 버튼으로 착각한 준비 오류와 색채 지형에서도 빨강 우세를 요구한 부적절한 픽셀 기대값을 확인했다. 이를 제품 결함으로 집계하지 않았다. Canvas의 모드 전환 탐색은 통과했지만, 준비를 바로잡은 WebGL 화면 탐색은 지연되어 중단했다. 미완성 탐색용 검사는 정식 회귀 검사로 추가하지 않았고 원시 출력은 `test-results-terrain-material-*`에 보존했다. 이번 변경에 지형 렌더링 수정은 없으며, 제보 현상은 미해결·추가 재현 대상으로 남긴다.

보기 UI·표시 설정 연결만 수정했다. GIS 원본·형상·지형 자료는 변경하지 않았다. 이 보고서의 메뉴 검증을 지형 문제 해결이나 공개 배포 완료로 해석하지 않는다.
