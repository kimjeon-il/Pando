# 판도편집기 조사·검증 보고서 — work/auto-georef

`Pando/reports/`는 웹·앱의 사람이 읽는 **독립 조사·검증 보고서 정본**입니다. 작성 시 [TEMPLATE.md](TEMPLATE.md)에 따라 보고서 ID, 상태, 출처 커밋, 실제 실행한 검사와 미실행 검사를 기록하고 이 색인을 갱신합니다. 보고서가 존재한다고 해서 지도 반영, 재검증 또는 배포가 완료된 것은 아닙니다.

이 문서는 2026-10-14의 **이 브랜치 보고서 위치 정리**만을 색인합니다. `main`의 모든 보고서 및 다른 브랜치의 현재 작업을 동기화했다는 뜻이 아닙니다. 기술 계약·규격·설계·작업 계획·혼합 진행 기록, 원본 GIS/데이터, 기계 생성 파일과 테스트 로그는 원래 소유 경로에 보관합니다.
