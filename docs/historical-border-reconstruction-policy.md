# 역사적 국경·해안선 복원 공통 작업 규칙

> **적용 범위:** 현재 판도연구소의 역사 GIS 조사·원본 제작·표시 파생본 검토에 사용하는 국제·국내 경계선, 국가·행정구역 외곽선, 하천 경계, 해안선·간척지·도서 변화 복원. 특정 국가·시대에 한정하지 않는다. 과거 문서의 '판도편집기'는 별도 폐기된 편집 제품의 역사적 명칭이다.
>
> **목적:** 국가의 성립·소멸·분열·병합과 주요 영토 확장·축소를 이해하기 쉽게 보여준다. 현재 단일 Web Viewer의 조사·데이터 제작에 공통 선별·복원·일반화 기준을 적용한다. 당시 Web/App 동등 적용 요구는 별도 앱 개발 지시로 재해석하지 않는다.
>
> **기본 원칙:** **거시적인 영토변화를 우선하고, 표시용 형상은 Natural Earth 1:10,000,000(천만 분의 1, 1:10M) 수준의 디테일로 맞춘다.** 주요 사건의 연대·귀속과 필요한 지형의 존재·연결성을 확인하되, 모든 미세한 변화와 굴곡을 복원하지 않는다.

## 0. 반영할 사건과 생략할 변화

| 분류 | 기본 처리 |
|---|---|
| 국가의 성립·소멸·분열·병합, 주요 영토 확장·축소 | 우선 조사·복원 |
| 작은 필지 교환, 측량에 따른 미세 경계 조정 | 원칙적으로 개별 복원 생략 |
| 소규모 퇴적·침식·하천 이동, 계절적 수위·유량 변화 | 원칙적으로 별도 형상 버전·국경 사건으로 만들지 않음 |
| 국가의 존재, 주요 도시·중요 도서의 귀속을 설명하는 작은 변화 | 역사적으로 중요한 예외로 선별 반영하고 이유 기록 |
| 거시적인 해안 윤곽·주요 도서의 존재·연결성을 바꾸는 간척 등 | 별도 해안 조사에서 선별 검토 |

- 작은 변화라는 이유만으로 중요한 사건을 누락하지 않으며, 법적 귀속 변화라는 이유만으로 모든 필지·마을 변동을 필수 조사 대상으로 만들지도 않는다.
- 생략한 변화는 조사 범위와 생략 이유를 간략히 기록한다. 생략 대상의 전 세계 완전 목록 작성이나 세부 벡터화를 종료 조건으로 요구하지 않는다. 생략은 그 변화가 역사적으로 없었다는 뜻이 아니다.
- 국가의 존재와 선택한 주요 사건의 연대·귀속은 표현 축척과 별도로 확인한다. 작은 소국을 일반화 과정에서 소멸시키지 않는다.

## 0.1 화면 식별에 따른 실무 선별 기준 — 2026-11-04

불필요한 미세 조사를 줄이기 위해 일반적인 영토 변화는 **실제로 달라진 연결된 구역의 면적 약 500km² 이상**을 상세 조사·개별 형상 복원의 우선 선별 기준으로 삼는다. **약 500km² 미만의 작은 변화는 원칙적으로 개별 정밀 복원을 생략**하고 범위·이유만 짧게 남긴다. 이는 §0의 거시적 사건 선별을 돕는 작업 기준이며, 보편적인 최소 가시 면적·위치 정확도·모든 사건의 수록을 약속하는 하한이 아니다. 종전의 픽셀 크기 계산만으로 정한 잠정 기준은 이 기준으로 대체한다.

- 면적은 국가 전체의 순증감이 아니라 실제 달라진 연결된 구역을 본다. 상쇄되는 취득·상실 면적이나 서로 떨어진 미세 필지를 합산하여 기준을 통과시키지 않는다.
- 500km² 이상이어도 길고 가는 띠는 잘 보이지 않을 수 있다. 면적 기준 통과가 자동 반영을 뜻하지 않으며 형상·유효한 폭·경계 이동량·대비·국경선 두께와 표시용 일반화 후 남는 윤곽을 함께 판단한다. **별도의 고정 폭·경계 이동량 수치 기준은 두지 않는다.** 반대로 §0·§3의 국가 존재, 주요 도시·중요 도서의 귀속, 역사적으로 중요한 사건과 필요한 통로·연결성은 크기와 관계없이 예외로 선별하고 이유를 기록한다.
- 기존 문헌·가용 형상에서 알 수 있는 대략적인 규모로 먼저 선별한다. 기준 적용을 위해 모든 작은 사건을 새로 정밀 측량·벡터화하거나 생략 대상의 완전 목록을 만들지 않는다. 규모가 불명확하면 그 불확실성을 남기고 주요 사건을 우선하며, 이미 판독 가능한 필요한 경계의 복원을 세부 필지 조사 때문에 멈추지 않는다.
- 선정 근거는 2026-11-04 사용자가 실제 공개 웹 최대 확대 캡처에 경계 변화를 가상으로 적용한 전후 이미지를 비교한 관찰이다. 사용자는 100km²는 식별하기 어렵고 약 500km²부터 식별된다고 판단했다. 비교는 공개 웹 코드 `7cabf3cde8a9`, 지구본 최대 32배, 지도 영역 1180×709 CSS px(전체 캡처 1180×757px), DPR 1 조건이다. 화면 중앙의 국소 근사에서 약 641m/px이며, 250·500·1,000km² 예시와 같은 500km²의 서로 다른 모양을 비교했다.
- 예시는 원본 캡처의 경계 주변 화소를 이동한 **모의 비교**이며 실제 역사적 영토 변화, 제품의 지오메트리·단순화 처리 시험이나 독립 측량이 아니다. 사용자 관찰을 작업 우선순위에 반영한 것이며 모든 사용자·화면·지역에 통하는 식별 임계치를 실증한 것은 아니다. 비교에 사용한 이동 폭은 모양을 달리하기 위한 조건이지 필수 폭 기준이 아니다.
- 원자료·표시 형상은 이미 일반화되어 있으므로 실제 국경선과 차이가 있을 수 있고, 확대해도 원자료에서 사라진 형상은 복원되지 않는다. 화면 크기·DPR·배율, 화면 중심에서 벗어난 투영 압축, 형상·폭·대비에 따라 보이는 정도가 달라진다. Natural Earth 1:10M을 일률적인 거리 오차로 환산하거나 면적 기준을 위치 정확도로 해석하지 않는다.
- 이 기준으로 기존 원본·채택한 마스터를 일괄 삭제·단순화하거나 완료한 지역을 재조사하지 않는다. 화면·줌·DPR 변경이나 수치 기준 통과 여부만으로 복원 정밀도를 높이거나 추가 검증을 의무화하지 않는다. 원본 보존·불필요 조사자료 정리는 각각 §5·§8의 기존 범위를 유지한다.

## 0.2 기존 소규모 연구의 종료 — 2026-11-04 추가 지시

사용자의 별도 폐기 지시에 따라 **기존에 조사한 항목 중 변경 면적이 500km² 미만으로 확인되는 상세 연구는 활성 조사·정밀 복원 대기에서 종료**한다. 이 기존 연구 정리에서는 과거 작은 사건의 중요성·예외 선정만으로 작업을 계속하지 않는다. 더 큰 사건의 분리 불가능한 일부, 국가 존재 자체의 면적, 면적·범위 미확정 항목은 작은 변경량으로 임의 분류하지 않는다.

- [라이브러리의 폐기 목록과 적용 범위](https://github.com/kimjeon-il/PandoLab-library-data/blob/work/gis/reports/borders/history/sub500-research-retirement-2026-11-04.md)를 따른다. 해당 항목의 옛 추가조사·hold 해소 권고는 현행 작업 지시가 아니다.
- 연구 종료는 실제 채택 지오메트리·원도·혼합 원자료의 삭제나 역사적 사건의 부정을 뜻하지 않는다. 사실·출처·종전 검증은 되돌릴 수 있는 감사 이력으로 보존하고, 작은 사건의 정밀 복원 때문에 더 큰 작업을 멈추지 않는다.
- 전체 보관 자료를 새로 측량·벡터화하여 면적을 확정하는 재조사를 요구하지 않는다. 확인된 범위와 미확정·접근하지 못한 범위를 구분하고, 보고서 정리만으로 main·런타임·자료 핀을 변경하지 않는다.

## 1. 외부 벡터와 역사 사료 선정

- §0에 따라 조사할 사건을 먼저 고른 뒤 기존 공간 데이터(SHP ZIP, GeoPackage, GeoJSON 및 공식 GIS 서비스)를 우선 탐색한다. 벡터가 없거나 부정확한 구간만 고지도 중첩·지오리퍼런싱·수작업 복원으로 보완한다.
- 해당 시점의 유효기간, 원측량·발행·개정 이력, 제공기관, 권리와 형상 범위를 확인한다. 표지 연도를 지도 내용의 기준연도로 단정하지 않으며, 현대 행정구역 형상을 근거 없이 과거 국경으로 소급하지 않는다.
- **원본 사료 축척과 최종 표시 수준은 별개다.** 주요 경계 노선과 사건의 귀속을 확인할 수 있는 시대 적합성 높은 자료를 선택한다. 특정 상세 축척을 기본 권장값이나 필수 조건으로 두지 않는다.
- 세밀한 지도·지적도·표석 자료는 중요한 도시·도서의 귀속, 주요 분기점 등 구체적인 쟁점이 있을 때만 추가 조사한다. 상세 사료가 있어도 모든 굴곡·표석을 따라 그릴 의무는 없다.
- 자료의 지오리퍼런싱 품질, 판독 불확실성과 공간 정확도는 별도로 기록한다. 오래된 지도가 제공하지 않는 정밀도를 주장하지 않는다.
- 원본을 보존하고 변환·일반화 결과는 파생본으로 취급한다. 변환 성공이나 같은 원본의 반복 비교를 독립적인 역사 검증으로 간주하지 않는다.
- 자료 수집·보고 절차는 [역사 GIS 벡터 자료 우선 탐색 운영 규칙](historical-vector-source-workflow.md)을 따른다. 1801년 이후 자동 조사의 기간과 국가 존속기간 조사·별도 해안 조사의 구분은 유지한다.

## 2. 표시 수준과 검토 종료 — Natural Earth 1:10M

| 항목 | 기준 |
|---|---|
| 표현 기준 | 기존 Natural Earth 1:10,000,000 국가 경계의 일반화 수준 |
| 비교 방법 | 대상과 참조를 같은 투영·범위·표시 배율에 놓고 주요 윤곽·굴곡·접합을 비교 |
| 조사 종료 | 선택한 주요 사건의 연대·귀속과 국가의 인식 가능한 형상이 뒷받침되고 필요한 위상이 유효함 |
| 추가 확대 | 끊김·자기교차·틈·겹침 등 기술적 오류 확인의 보조 수단; 미세한 역사 변화의 추가 복원 요구로 사용하지 않음 |

- 이 기준은 **표현 복잡도와 작업 범위의 기준**이다. Natural Earth의 현대 형상 자체가 특정 과거 시점의 역사적 정확성을 입증하지는 않는다.
- 축척을 일률적인 미터 허용오차나 삭제 거리로 치환하지 않는다. 국가 크기·형태·중요 예외에 따라 일반화 강도를 조절하며, 정점 수나 좌표 소수점 자릿수를 맞추는 것을 목표로 삼지 않는다.
- §0.1의 약 500km² 기준은 작업 선별을 위한 참고값이며 위치 허용오차·삭제 거리·필수 화면 검사나 새로운 종료 관문이 아니다. 사용자 모의 비교 관찰, 화면 계산 추정, 실제 형상 검증과 독립 측량을 서로 구분하여 기록한다.
- 앱 최대 확대에서 보이는 잔굴곡이나 서브픽셀 편차를 없애기 위해 조사를 계속하지 않는다. 확대 상한·모니터 해상도·DPR이 바뀌어도 그 사실만으로 역사 복원 정밀도를 높이지 않는다.
- 독립적인 역사 기준선이 있을 때 필요한 위치 차이를 측정할 수 있으나, 모든 구간의 수치 검사를 종료 조건으로 요구하지 않는다. 육안 비교는 `육안 확인/정량 미측정`으로 구분하고, 측정하지 않은 정확도를 통과로 표시하지 않는다.
- 고해상도 원본이나 기존의 세밀한 벡터를 이미 확보한 경우 보존할 수 있다. 이 문서 개정이 기존 자료의 일괄 단순화·삭제를 지시하지는 않는다.

## 3. 일반화 후에도 유지할 핵심 사항

1. **주요 사건의 연대·귀속:** 선택한 영토변동의 조약 효력일·이양일·실효지배 기준을 혼동하거나 주요 영토를 잘못 배치하지 않는다.
2. **국가와 중요한 예외의 존재:** 소국, 주요 도시·중요 도서의 귀속 등 §0에서 채택한 예외가 일반화로 소멸하거나 뒤바뀌지 않게 한다.
3. **필요한 연결 관계:** 선택한 사건을 설명하는 영토·주요 도서·통로의 연결과 분리를 유지한다. 관련 하천·해안의 역할을 확인하되, 미세한 물가선 변동까지 추적하지 않는다.
4. **지오메트리 유효성:** 경계 단절·자기교차·중복, 의도하지 않은 슬리버·구멍, 인접 형상 사이의 틈·겹침을 만들지 않는다.

이는 작은 필지·마을·모든 섬의 귀속 변화를 예외 없이 조사하라는 요구가 아니다. 미세한 차이는 §0의 생략 원칙을 따르고, 추가 조사할 중요한 예외는 그 필요성을 명시한다.

## 4. 조사·복원·일반화 순서

1. **사건 선별:** 거시적 영토변화와 중요한 예외를 정하고, 미세 변화의 생략 범위를 기록한다.
2. **자료 대조:** 적합한 기존 벡터를 우선 확보하고 주요 경계 노선·귀속·일자를 독립 사료와 확인한다. 필요한 구간만 고지도로 보완한다.
3. **주요 형상 복원:** 사건을 이해하는 데 필요한 경계부터 마스터에 복원한다. 변화가 없다고 확인된 해안선·국경은 기존 기준선을 재사용하며, 나중에 생략할 잔굴곡을 끝까지 추적하지 않는다.
4. **표시용 일반화:** 원본·마스터를 보존한 별도 파생본에서 디테일을 줄인다. Natural Earth 1:10M 참조와 같은 조건으로 비교하고 공유 국경을 함께 처리한다.
5. **종료 판단:** 주요 사건의 설명, 인식 가능한 국가 윤곽, §3의 핵심 사항이 충족되면 종료한다. 남은 미확인 사항은 기록하고, 중요한 근거가 부족한 구간은 `working` 또는 `provisional`로 유지한다.
6. **최종 반영과 인계:** 승인된 범위만 기존 형상 버전·시점·객체 ID 계약에 따라 반영한다. 완료·생략·보류 범위, 실제 검사와 다음 작업을 짧게 기록한다.

종료는 **이 제품의 거시적 역사 지도 목적에 충분하다**는 의미이며, 모든 국경 사건을 수록했거나 지적 수준의 정확도를 보증한다는 뜻이 아니다.

## 5. 원본 데이터와 표시용 데이터 분리

- 확보한 출처·원본 지오메트리·복원 마스터는 보존한다. 표시용 일반화 때문에 원본의 정점을 직접 삭제하지 않는다.
- 표시용 파생본은 국가 크기·형태에 맞춰 일반화한다. Douglas–Peucker 등은 후보 도구이며, 단일 거리나 보존 비율만으로 천만 분의 1 표현에 적합하다고 판정하지 않는다.
- 주요 분기점, 공유 국경 접속점, 중요한 예외의 형상을 보호한다. 인접 국가·행정구역이 공유하는 경계는 한 번의 일관된 처리로 양쪽에 반영해 틈·겹침을 방지한다.
- 웹과 앱은 같은 표현 목표를 따른다. 최대 줌 수치의 일치나 더 엄격한 화면 분해능을 새로운 역사 복원 의무로 삼지 않는다.
- 이 규칙은 **작업 선택·검증 지침**이다. 제품 줌, 렌더러, 좌표 파일, 자동 단순화 코드나 검사 로직을 변경하라는 지시가 아니다. 렌더러·메시의 기술적 정확도 검사는 별도로 유지한다.
- 참고: [Natural Earth 제작 지침](https://www.naturalearthdata.com/about/data-creation/)은 기존 벡터를 일반화의 참조로 사용하고 지형의 크기·복잡도에 따라 강도를 조절하도록 안내한다.

개별 작업에서 사용자가 명시적으로 승인한 변경별 검토 게이트는 별도로 구현할 수 있다. 이 경우 변경된 입력만 검사하고, 읽기·정규화에 전역 검사를 추가하거나 기존 미검토 형상을 검토 완료로 간주하지 않는다. 이 예외는 전 세계 자동 단순화나 전체 GIS 검사 승인을 뜻하지 않는다.

## 6. 보고 상태 구분 및 최소 기록

기존 보고 상태의 이름과 의미를 유지한다. 수치 검사가 모든 조사 단계의 필수 관문은 아니다.

| 상태 | 의미 |
|---|---|
| `source-indexed` | 원본 지도·연도·서비스 목록만 파악 |
| `overlay-reviewed` | 원본과 후보선을 중첩·육안 검토; 독립 기준선과의 수치 비교는 미완료 가능 |
| `screen-delta-checked` | 독립적인 기준 경계가 존재하여 화면상 위치 차이를 수치로 검증 |
| `historically-verified` | 연대·귀속·필수 위상 조건과 확인된 차이를 함께 검증 |
| `provisional` | 부족한 증거·미해결 예외가 남아 있어 마스터 최종 승격 불가 |

선택한 사건·구간마다 **적용 날짜 / 소스(측량·발행·개정 연도) / 주요 경계 근거 / 작업·생략 범위 / 중요한 예외와 선정 이유 / 일반화 방법 / 참조 판본·비교 투영·범위·배율 / 실제 검사 또는 미실행·미측정 / 반영·보류 여부**를 간략히 기록한다. §0.1로 생략한 경우 가용 자료의 대략적 규모 또는 중요 예외 여부와 생략 이유만 덧붙이고, 이를 위해 별도 정밀 측정을 요구하지 않는다. 생략한 미세 변화는 검증된 부재로 취급하지 않으며, 기존 보고서의 실제 측정값과 당시 판단을 새 기준의 검증 결과로 바꿔 적지 않는다.
