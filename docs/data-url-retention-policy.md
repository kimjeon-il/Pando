# GIS 데이터의 구버전 URL 유지 정책

- **적용일: 2026-10-09**
- 웹 저장소: `kimjeon-il/Pando`; 앱 저장소: `kimjeon-il/PandoEditor`.
- 이전 방침인 **구버전 정적 데이터 URL 영구 보존 의무를 해제**한다. `https://kimjeon-il.github.io/Pando/assets/data/...`의 더 이상 사용하지 않는 버전 파일은 승인된 정리 후 `404`가 될 수 있다. 과거 링크에 대한 자동 리디렉션·대체 호스팅·동일 URL 지원은 보증하지 않는다.
- **현행 제품이 참조하는 파일의 존재와 원본 무결성은 계속 보장**한다. 현재 웹 데이터/정적 지형 런타임, Web Worker/생성기 입력, 앱 내장 또는 출처 매니페스트에서 지정한 자산, 유효한 데이터 테스트 fixture는 정리에서 제외한다. 버전 숫자가 낮다는 이유만으로 사용 중인 파일을 삭제하지 않는다.
- 2026-10-09 당시의 예: 사용 중이던 지형 `terrain/v0.12.6/**`와 수계의 참조 자산을 유지했다. 이후 개별 전환 승인을 받은 영역은 아래 후속 정책을 따른다.
- **첫 번째 개별 삭제 승인:** 웹 `assets/data/terrain/v0.12.0/` **335개 파일, 374,094,147 bytes**. 웹의 현존 브랜치에 같은 경로와 바이트가 있을 때만 삭제한다. 앱의 `assets/world/**`·이전 릴리스 파일은 대상이 아니다.
- 이번 정책 변경은 **모든 구버전 자산을 일괄 삭제하라는 포괄 승인과 다르다.** 다음 버전 그룹은 별도 런타임/앱 의존 확인과 구체적인 정리 결정이 필요하다.
- 삭제는 정확한 Git Blob·크기·브랜치 원본 커밋을 기록하고, 변경 대상이 다른 경우 중지한다. 파일 외 코드·기능·국가 데이터의 무관한 변경을 병합하지 않는다. 복원은 해당 브랜치의 삭제 전 Git 커밋에서 가능하며, 기존 Git 이력·브랜치를 강제로 지우지 않는다.
- 브랜치마다 삭제 뒤 현재 지도/지형/수계 참조를 재검증한다. `main` Pages에 적용할 때는 이전 버전 URL의 접근 중단이 이번 정책 변경에 따라 허용되지만, **현재 버전 URL·GIS 가져오기 기능·앱 오프라인 동작 손상은 허용되지 않는다.**
- 배포 방식 변경(GitHub Pages branch→Actions), `work/gis` 제품 코드의 `main` 병합은 이 URL 정책 변경만으로 자동 승인되지 않는다. 두 작업은 각각 별도 검증 후 수행한다.

## 2026-10-12 DEM 미리보기 전환

통합 저장소 `work/gis`에서 기존 `assets/data/terrain/v0.12.6/`의 335개 파일
(367,620,868 bytes)을 DEM 유래 미리보기 `terrain-preview/v0.13.3-p1/`로
교체하는 승인을 적용한다. 앱 `native/`의 구 raster manifest와 inventory
참조도 교체한다. DEM 주 자료, 현재 지형 계산과 저장 계약은 유지한다.

검증 후 구 raster 파일은 현재 트리에서 제거하며 Git 이력은 보존한다.
전환이 배포된 뒤 기존 공개 URL은 404 또는 410이 될 수 있고 보장하지 않는다.
원본 앱 백업 저장소, 과거 fixture·원본 코드·조사 기록은 보존한다.
새 미리보기의 출처·동일 바이트·오프라인 표시 기준은
[DEM 지형 표시 계약](terrain-preview.md)을 따른다.
이 승인은 `main` 병합·배포·포터블 제작을 포함하지 않는다.
