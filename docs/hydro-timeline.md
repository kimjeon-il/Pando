# 강·호수의 공통 기간별 형상

국가와 편집 수계는 C++ `TimelineRecords` schema 3의 같은 검증·해석·편집 경로를 쓴다. 소유자는 `ObjectRef { domain, id }`이고 `territorial`, `hydro`, 읽기 전용 원자료의 `hydroBuiltin`을 구분한다. 물 객체에는 행정 부모나 국기를 부여하지 않는다.

`HydroFeature`는 정체성과 속성만 저장한다. `geometryBindings`가 `GeometryRef`와 포괄적인 `validFrom`/`validTo`를 연결하며, 정본 `hydroEdits[].geometry`는 null이다. 지오메트리 저장소는 모든 이력을 보존한다. 라이브러리는 기존 `geometryVersions` 계약을 강·호수에도 사용한다.

날짜 해석은 같은 C++ resolver를 사용한다. 월 커서는 월말이며, 자료 조회의 정확한 일자도 양 끝 포함으로 해석한다. 존속기간과 형상 제공 범위는 별개다. 형상이 없는 기간은 표시되지 않으며 과거 전체로 현대 형상을 추정하지 않는다. 국가의 기존 부모·형상 대응 검증은 유지한다.

형상 연결의 선택 항목 `rendering`은 `stroke_width`, 정점 순서와 같은 `stroke_widths`(선 조각별 배열), `border_aligned`, `connectivity`를 소유한다. 정체성의 불변 메타데이터와 중복 저장하지 않는다. 좌표 편집 후 기존 정점 폭과 연결은 제거하고, 폭 기본값은 유지한다. 원본 라이브러리의 다른 버전은 바꾸지 않는다.

편집·복사·일괄 삭제는 기존 명령과 ChangeSet으로 적용한다. 기간 편집은 기존 객체의 월별 분리 규칙을 따른다. Undo/Redo, 저장·불러오기, 라이브러리 임시 편집에도 같은 형상 저장소와 기간 기록을 사용한다. 하천 분할에는 현재 문서가 해석한 하천 형상과 폭·연결 정보를 전달한다.

기본 수계의 타일·배율별 로딩은 유지한다. 이미 로드한 기본 수계의 정체성과 형상 연결을 공통 resolver에 제공하며, 날짜 조회만으로 전체 수계를 다운로드하지 않는다. 렌더러 준비 키는 GeometryRef, 실제 폭·색·정렬과 FID 배치에 의존한다. 동일 형상의 날짜 이동·이름 변경은 준비나 업로드를 요구하지 않는다.

카스피해는 `waterbody:caspian` 객체의 현대/복원/현대 연결이다. 아랄해는 별도 `waterbody:aral` 객체의 과거 형상 연결이며, 그 밖의 시점에는 기존 남·북아랄 기본 객체를 유지한다. 두 호수의 과거 표시 기간은 사용자 승인에 따라 **1922-01-01~1929-12-31 양 끝 포함**이다. 이 구간은 표시 정책이지 호안의 실제 변화일이나 측량 유효기간이 아니다. 호수 존속기간은 별개이며 건국일처럼 1922년을 입력하지 않는다.

`tools/physical-water-catalog.mjs`는 라이브러리 정본 `geometryVersions`의 기간을 schema 3 기록과 불변 자산 참조로 투영하고 공통 C++ 검증기에 맡긴다. 별도 배경 날짜 선택기는 없다. 공통 선택 결과가 복수 호수일 때는 모두 동일한 육지 파생 자산을 가리켜야 하며, 물체별 정체성·형상 버전은 분리한다. 화면에 넘기는 수면 채움만 합성한다. 현대 기본 수계의 표시 대체는 선택된 자산의 명시적 `replaces` ObjectRef 관계이며, 로딩 성공 전이나 실패 시에는 원본 표시를 유지한다. 원래 객체의 존속기간·좌표를 바꾸지 않는다.

카스피 복원은 여러 연대의 지도학적 근사이고 아랄 복원은 1926년 인쇄 Prasolov 지도를 바탕으로 한 승인 후보다. 둘 다 정확한 1922년 측량 수역이 아니다. 카스피의 현대 자료는 Natural Earth 5.1.1 비교 기준이며 2026년 실측이라는 뜻이 아니다. 편집 복사본이 있으면 각 물체의 현재 형상으로 국소 육지 마스크를 파생하고 해당 수역 채움의 소유권은 일반 편집 수계 렌더러로 넘긴다. 국가 영토에서 수역을 차감하지 않는다. 도서 구멍·원자료·NOT_COAST 의미는 그대로 보존한다.

검사는 작은 합성 국가·강·호수와 카스피해의 직접 출력으로 한정한다. 새 역사 수계 복원, 전체 검사·벤치마크·Windows 실행파일 재빌드, main 통합·배포는 이 작업에 포함하지 않는다.
