# 구버전 GIS URL 정책 변경 (2026-10-09)

## 확정 정책

- 더 이상 사용하지 않는 구버전 자산의 공개 URL은 유지하지 않는다. 제거 후 HTTP 404는 허용한다.
- 현재 실행 중인 웹·앱 코드가 참조하는 데이터, 앱 내장 데이터, 역사적 재현을 위한 Git 이력은 유지한다.
- 최초 정리 대상은 웹 `assets/data/terrain/v0.12.0/`의 335개 파일(374,094,147 bytes)로 한정한다.
- 현재 지형 버전 `v0.12.6` 및 현행 수계·국가 자산은 보존한다.
- 7개 웹 브랜치에서 고정 HEAD 및 대상 Git Blob 일치 여부를 검사한 뒤 일괄 정리한다. 다중 브랜치 업데이트는 원자적이지 않으므로 각 HEAD를 복구 지점으로 기록한다.
- 기존 URL 전수 보존 검사는 더 이상 삭제 승인 조건이 아니다. 현행 런타임/빌드 참조 및 삭제 대상 이외의 변경 방지가 승인 조건이다.
- Pages 소스 전환, `main` 제품 코드 병합, 다른 구버전 파일 삭제는 별도 작업으로 유지한다.

## 기존 보고서와의 관계

7~10단계 문서에서 모든 구 URL을 영구 보존하도록 요구한 부분은 이 신규 정책으로 대체한다. 과거 검증 결과 자체는 변경하지 않는다.
