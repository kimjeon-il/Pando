# 구형 수계 v0.12.2~v0.12.6 — 2단계 삭제 준비 조사

- 작성일: 2026-10-09
- 작업 브랜치: 웹 `work/gis`; 웹·앱 기존 데이터는 변경하지 않음
- 범위: 웹 모든 브랜치, 앱 모든 브랜치, 런타임·생성기·테스트·배포 참조

## 조사 대상 및 기존 의존성

구형 수계 5개 버전의 1,769개·153,982,948 bytes가 웹 7개 브랜치에 있음. 현재 웹·앱은
v0.13.1과 v0.13.0 공유 바이너리를 사용하므로 이 둘은 삭제 대상에서 제외.

- `tools/report-hydro-v0124.py`: v0.12.3과 v0.12.4를 직접 입력으로 읽어 과거 수계 비교를 작성
- `tools/repack-water-v0125.py`: v0.12.4를 입력으로 읽고 v0.12.5를 출력으로 생성

## 감사 방법

1. 각 브랜치의 전체 Git 트리에서 정확한 구 수계 파일 경로·Blob SHA·크기 비교
2. 각 웹 브랜치의 실제 수계 환경설정 및 현행 매니페스트의 의존 경로 폐쇄 검사
3. 각 앱 브랜치의 v1/v2 내장 manifest·물리 데이터 인벤토리 출처 검사
4. 과거 바이너리를 내려받지 않는 부분 클론에서 생성기·테스트·앱 런타임·문서 직접 참조를 구분
5. 버전별 보류/후속 삭제 후보 및 1,769개 파일의 정확한 복원 Commit·Git Blob 증거 산출

## 결과 확인

실제 CI 실행 이후 버전별 분류·예상 용량과 검증 링크를 여기에 기록한다.
CI의 JSON artifact는 모든 개별 파일 경로, SHA, 크기, 소스 사용처, 기준 커밋을 포함한다.

## 변경 금지 조건

이 단계에서 구형 수계 파일 실제 삭제, 수계 최신 데이터 재압축·수정, 앱 원본 교체,
Pages 배포 방식 변경, 타 영역 코드 병합은 모두 수행하지 않음.
과거 앱 릴리스나 사용자 자체 프로젝트에서 고정한 구 URL은 미확인 위험으로 명시한다.
