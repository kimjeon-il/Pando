# 공통 지도·열람 구조 정리 실행 계획

사용자가 승인한 2026-10-19 대화의 계획을 실행한다. 기준 커밋은 `264fff61`이며 기존 `work/ui` 미커밋 작업은 보존한다.

## 계약

- 웹·앱은 표시 규칙과 소유자를 공유한다. 제품 차이는 기능 허용과 화면 조립이다.
- 같은 모드의 상위·하위 경계는 위치·접촉·해안·시점·표시 판정을 공유하고 선 모양만 다르다. 한 선은 한 출력 경로만 소유한다.
- Worker 실행 의존성 전체를 내용 해시로 식별되는 생성 자산에 포장한다. 기존 자산 수집·공식 생성·staging 경로에 통합한다.
- 지형의 육지 마스크는 기존 지형 제작 원본으로부터 얻고 정치 객체의 존재·표시·색과 분리한다.
- `ProjectSession`의 보기 설정 저장·복원은 대칭이며 문서/dirty/Undo에 영향을 주지 않는다.
- 검색은 현재 시점에 존재하고 표시가 켜진 전체 객체를 대상으로 하며 viewport/zoom/collision에 제한되지 않는다.
- 내장 지명의 시점별 표시·이름 규칙도 조회 소유자에서 공유한다. 과거 존속기간을 추측하지 않는다.
- 제거된 검색 폴더 구조·미사용 포트·상태·테스트를 제거한다. 분포도 동작·저장 형식·UI 설계·편집/네이티브 내부 재작성은 제외한다.

## 실행 순서

1. Worker 자산 생성/로드/제품별 closure와 stale-cache 회귀 검사.
2. 공통 경계 정책/출력 소유자와 실제 원본·내장 지도 회귀 검사.
3. 독립 물리 육지 배경과 Canvas/WebGL 시점·숨김 회귀 검사.
4. 보기 복원, 공통 검색·표시·선택, 상태 표시와 불필요한 이전 코드 제거.
5. 영향 단위·브라우저·staging 검사, 독립 검토, 보고서/색인 및 필요 시 승인된 게시 검증.

각 단계는 실패하는 검사→기존 소유자 수정→관련 검사 통과 순서로 수행한다. 전체 스위트는 기본 실행하지 않는다. 출처 SHA·실행 검증·미실행 native 항목을 구분해 `reports/`에 남긴다.
