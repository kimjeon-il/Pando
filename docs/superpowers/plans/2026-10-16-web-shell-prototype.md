# Windows·Android 웹 기반 시험용 앱 구현 기록

사용자가 채팅에서 승인한 구현 계획과 실행 범위를 고정한다. 구현 브랜치는 `work/ui`이고 기존 Qt 앱은 실행하거나 교체하지 않는다.

## 승인된 결과

- 같은 웹 UI·WebGL 렌더러·Worker·manifest 검증을 거친 WASM을 Tauri 2에 포함한다.
- Windows는 실제 시험용 앱을 작은 자료로 실행한다. Android는 arm64 디버그 APK 빌드까지 수행하며 기기·에뮬레이터는 실행하지 않는다.
- fixture는 가상 국가 2개·하위 객체 1개, 입력 좌표 15개다. 전체 세계·지형·수계·지명 자료 자동 로딩을 막는다.
- 자동저장·실제 Core 명령·Undo/Redo·현재 GeoPackage 코덱·네이티브 파일 저장과 재실행을 검증한다.
- 포터블·설치 프로그램·main 반영·푸시·배포는 만들거나 실행하지 않는다.

## 소유권과 연결

`composeApplication`의 선택적 `platform` 포트는 기존 역사 자료 공급자, 배경 자료 사용 여부, 초기 메시 출처, 저장 namespace를 받는다. 인자가 없는 기존 웹 시작 동작은 유지한다. `onComposed`는 호출자가 명시한 경우에만 실제 런타임 소유자를 전달한다.

앱은 웹 소스를 `stage.mjs`로 복사해 실행한다. 앱 전용 시작 파일, 작은 자료, Worker 요청 차단, `resourceProfile: small-project` 빌드 설정만 추가한다. 이 프로필에서 사전 생성된 세계 메시 목록을 읽지 않고 기존 C++ 메시 계산 경로를 사용한다. 웹·코어의 기능 규칙을 다시 구현하지 않는다.

네이티브 연결은 고정 시험 파일, 진단 보고서, 사용자가 선택한 GeoPackage 파일에 한정한다. 입력은 1 MiB로 제한하고, 문서 가져오기는 객체 20개·좌표 100개 이하를 확인한 뒤 기존 Core에 전달한다. 로컬 파일 교체는 인접 임시 파일을 완성한 뒤 rename한다.

## 결정 및 진행

- Windows UAC를 사용자가 확인할 수 없어 MSVC 설치를 재시도하지 않는다. 기존 MinGW 13.1과 사용자 범위 Rust GNU 도구로 Tauri 빌드를 진행한다. 이 환경의 실제 성공 여부를 보고서에서 별도 기록한다.
- 현재 manifest에 고정된 Emscripten Embind의 `new Function` 사용을 CSP 사전 검사에서 확인했다. 앱에서 이 실행을 허용하며, 원격 콘텐츠·탐색·임의 파일 경로 접근은 계속 차단한다. WASM 바이너리는 재빌드하거나 변조하지 않는다.
- 파일 대화상자, Android 실제 실행, 전체 자료의 성능은 자동 내부 저장 검사와 구분한다. 실행하지 않은 항목을 PASS로 기록하지 않는다.
