# 바이코누르 KAB·KAZ 경계 검증 기록 (2026-11-03)

**결론: 기존 지도 형상의 좌표상 내부 정합성 통과. OSM 독립 법적 경계 대체는 아직 불가.**

대상: kimjeon-il/Pando work/gis, 고정 자료 kimjeon-il/PandoLab-library-data@91c127ddbae902405de6e35b38940a59a8c0d021.

## 공식 법령 및 시간

- 1994-12-10 조약 기준점 31개, 직선 29개; 시르다리야강 우안으로 지정된 17→18 및 31→1 구간은 정밀 독립형상 미확보.
- 2017-11-09 체결된 개정협정은 2019-12-25 비준, **2020-01-22 발효**. 네 반환 구역과 원래 퇴레탐·아카이 제외지가 기록된다.
- 별개의 2018-11-09 개정(2021-07-29 발효)은 임대기간을 2050년까지로 조정한 것으로, 국경 좌표 개정과 구별한다.
- 공식 조약 좌표의 원좌표계는 현재 확정되지 않았다. 2025년 위성 촬영의 물가를 1994년 법적 하천 우안과 동일하게 간주하지 않는다.

서로 다른 DMS 좌표 정밀도(8·9자리)로 인한 미세 교차 오탐을 실제 CI에서 발견해, 5cm 이하의 공통 노드 반올림만 교차 판정에서 제외했다. 정밀 측량 공차로 사용하지 않는다.

## 배포본 실형상 검사

- KAB: Polygon 링 4개, 외곽 39세그먼트, 내부 링 각각 11·6·7세그먼트.
- KAZ: 현재 MultiPolygon 링 10개.
- KAB의 전체 경계 **63/63 세그먼트가 KAZ에 동일 좌표로 존재**, 미일치 0.
- 공식 기준점 **31/31점이 기존 표시 외곽선에서 0.00m 이탈**. 조약 좌표를 반영했다는 사실만 입증하며 강변 굴곡은 독립적으로 입증하지 못한다.
- 기존 형상 메타데이터: OSM 파생 선형, 표시용 1km 단순화, 4 반환구역의 7.371787㎢ 과잉 제외, 퇴레탐·아카이 2.859003731㎢ 홀 생략.
- KAB는 1995-09-25 시작 단일 geometry version으로 2020-01-22 개정 전후를 구분하지 않음. KAZ에도 동일 OSM 파생원이 두 버전에 보존됨.

## 엄격한 완료 조건

1. 시르다리야강 17→18, 31→1의 강 우안을 독립 측량/영상 관측으로 복원하고 촬영 시기·하천 변동·흐름 방향을 검증.
2. 원조약 좌표계를 검증하고 도로·철도 제외 구역, 정착지 구역, 반환 4개 구역을 정본 기준으로 적용.
3. KAB/KAZ 동일 선분의 완전 위상 정합, 날짜별 경계 버전 및 재생성 데이터 SHA 보존.
4. 검수 완료한 데이터만 영구 저장·배포. 그 이전에는 기존 OSM 라이선스 표기 유지.

검증 코드는 tools/gis/verify-baikonur-lease-exclusions.mjs, tools/gis/validate-baikonur-independent-banks.mjs, tools/gis/audit-baikonur-current-runtime.mjs, tools/gis/audit-baikonur-runtime-geometry.mjs.

**이번 검증에서는 자료·경계·메인 출처 표기를 실제로 수정하지 않았다.**
