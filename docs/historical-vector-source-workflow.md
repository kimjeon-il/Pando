# 역사 GIS 벡터 공간자료 우선 탐색·재사용 운영 규칙

> 적용: `work/gis` 연도별 세계 역사 타임라인·국경/영토 조사. 2026-10-20 제정.
> 목적: 기존 Pando 지도 엔진·정본 형상·시간 모델은 유지하면서 외부 SHP, GeoPackage, GeoJSON을 **조사 후보**로 먼저 탐색하고, 검증 후에만 별도 승인을 받아 재사용할 수 있도록 한다.
> 상위 기준: [역사적 국경·해안선 복원 공통 작업 규칙](historical-border-reconstruction-policy.md). 본 문서는 그 기준의 조사·자료 수집 단계만 구체화한다.

## 1. 조사 우선순위

연도별 조사에서 국가의 성립·소멸, 국제적 지위 변경, 국제국경 또는 영토 귀속 변화가 확인되면 **해당 사건의 장소와 실제 효력일에 일치하는 공간자료 후보를 먼저 찾는다**.

1. **벡터 우선 탐색:** 국가 기록원·공식 GIS 포털·조약 부속도면과 학술 GIS 저장소에서 `.shp`(구성 파일을 포함한 ZIP), `.gpkg`, `.geojson/.json`을 찾는다. 관련 자료가 `WFS` 등 공간 서비스로 제공되는지도 확인한다. 범위·판본·제공기관·사용권을 기록한다.
2. **역사적 적합성 선별:** 공개·제작·측량·수정·데이터 유효연도를 분리한다. 2026년의 행정구역 SHP를 1801년의 역사 경계로 취급하지 않는다. 사건 서명일·발효일·현장 이양일·실효지배 기준도 혼동하지 않는다.
3. **공간자료 후보 검사:** 출처·저작권·재배포 가능 여부·좌표계·객체 식별자·국가/지역 범위·경계 정합성·도서/월경지 포함 여부를 점검한다. 후보를 확보했다면 원본을 유지하고 변환 결과와 비교한다.
4. **독립 역사 사료 대조:** 독립적인 조약·역사 지도·학술/공식 문헌과 국경 귀속 및 일자를 최소 2개 출처로 교차 검증한다. 같은 원본의 포맷 변환본 둘은 독립된 출처가 아니다.
5. **벡터 자료가 없거나 부정확한 구간만** 기존 작업 규칙에 따라 역사 지도 중첩·지오리퍼런싱·수작업 국경 복원을 우선순위에 넣는다. 부족한 범위만 보완하며, 후보 파일이 없었다는 사실을 해당 지역의 역사 경계가 존재하지 않았다는 뜻으로 해석하지 않는다.

대상 기간은 **1801-01-01부터 현재까지**이다. 연도별 자동 조사의 대상은 국가 성립·소멸, 국제 지위 변화 및 국가 간 국경·영토 변동으로 제한한다. **해안선 변화·간척·침식 및 해안 지형 복원은 기존 별도 조사로 유지하며 이 자동 조사에 편입하지 않는다.** 독립적으로 운영되는 국가 존속기간 순환 조사의 주요 범위를 벡터 수집으로 변경하지 않는다.

## 2. 자료원 탐색 시 주의

- [CShapes 2.0 — ETH Zürich](https://icr.ethz.ch/data/cshapes/): 전 세계 1886~2019, CShapes-Europe 1816년 이후 유럽의 역사 경계 후보. 여러 포맷이 제공되지만 **CC BY-NC-SA 4.0**이므로 배포·2차 가공·이용 목적에 맞는 권리 검토 전까지 후보 자료로만 취급한다. 범위 밖 시점은 이 자료로 채우지 않는다.
- [Natural Earth](https://www.naturalearthdata.com/downloads/50m-cultural-vectors/): 현재 세계 국가 경계 대조·렌더링 기준 후보. **역사적 대상일을 입증하지 않는 현대 자료**이며 과거 국경에 직접 대입하지 않는다.
- 각국 공간정보·국가기록원·조약 저장소·공식 행정구역 서비스와 개별 논문 부록을 해당 지역/시점에 맞춰 추가로 찾는다. 데이터가 WMS/이미지뿐인 경우는 '벡터 후보 없음/미확인'으로 기록하고 별도 역사 지도 대조를 진행한다.
- 서비스/원본이 가리키는 실제 축척과 공간 정확도가 중요하다. 포맷이 SHP라는 이유만으로 역사적으로 정확하거나 가장 정밀하다고 간주하지 않는다.

## 3. 변환은 임시 파생본으로만 수행

원본 SHP는 `.shp`·`.shx`·`.dbf`와 제공된 `.prj`/문자 인코딩 정보를 함께 취급하고 해시를 남긴다. `ogrinfo`로 레이어·필드·형상 타입·원본 CRS를 확인한 후, **원본 CRS가 확인된 자료에 한하여** GDAL `ogr2ogr` 등으로 GeoJSON 임시 파생본을 만든다.

```sh
ogrinfo -ro -al -so input.shp
ogr2ogr -f GeoJSON -t_srs EPSG:4326 -lco RFC7946=YES converted.geojson input.shp
```

GeoPackage는 레이어가 여럿일 수 있으므로 대상 레이어 이름을 지정해 동일하게 처리한다. 원본 CRS가 없거나 불분명하면 EPSG:4326으로 *지정하는 것*만으로 변환을 가장해서는 안 된다. 근거를 찾을 때까지 보류한다.

- 폴리곤/멀티폴리곤, 좌표 순서, 링·홀·섬·반경도선, 위상 유효성, 인접 국가의 공유 경계, 객체 ID와 유효 기간을 점검한다.
- 변환과 손실 없는 좌표·속성 보존을 구분한다. GeoJSON 변환 성공 = 독립적 역사 검증 완료가 아니다. 재투영·반경도선 처리·좌표 반올림·국가별 합집합은 지오메트리를 바꿀 수 있으므로 차이와 원인을 기록한다.
- 기존 GIS 정본·국가 객체/타임라인 자료, 웹·앱 코드 및 렌더러는 **수정하지 않는다**. 조사 중 변환 자료는 임시 검토용으로만 사용하며, 권리·완전성 검증 전 외부 파일을 그대로 제품 자산에 넣지 않는다.
- 승인된 실제 반영 작업이 별도로 시작될 때만, 검증된 변환본을 기존 지오메트리 버전/객체 ID/시점 계약에 따라 가져온다. 새 렌더러나 SHP 전용 소유자를 만들지 않는다.

## 4. 보고서 필수 필드와 결정

매 실행은 기존 조사 연도·지역 커서를 유지하고, 대상 사건/국경별로 다음을 `work/gis` 브랜치의 저장소 루트 `reports/geography/` 보고서에 표 또는 짧은 항목으로 남긴다.

| 필드 | 기록 내용 |
| --- | --- |
| 사건/공간 범위 | 사건 ID, 국가/접경 지역, 기준 일자 및 유효기간 |
| 후보 자료 | URL, 제공기관, 포맷(SHP/GPKG/GeoJSON/WFS 등), 발견/미발견, 자료명·판본 |
| 근거 | 측량일/발행일/갱신일, 원본 효력일, 확인된 역사적 범위, 독립 역사 자료 2개 이상 |
| 데이터 검증 | 실제 파일 열람·원본 CRS·레이어·형상/속성·해시·변환 여부, 가용/미실행 검사 |
| 사용 권리 | 라이선스, 저작자·표기, 재배포 및 파생물 사용 조건 |
| 판단 | `source-indexed` / `overlay-reviewed` / `screen-delta-checked` / `historically-verified` / `provisional`와 검증·보류 이유 |
| 후속 | 벡터 사용 후보 / 다른 자료 추가 대조 / 지도 중첩·수작업 복원, 미해결 구간 |

**후보 미발견도** 조사 검색 범위·출처와 함께 기록한다. 파일과 페이지를 열어 보지 않았다면 '원본 미열람', 실제 변환하지 않았다면 '변환 미실행', 독립 역사 기준선이 없으면 '0.5 CSS px 검사 미실행'이라고 표시한다.

현행 `docs/historical-border-reconstruction-policy.md`의 최대 배율·0.5 CSS px·귀속 및 토폴로지 우선 정책을 유지한다. 조사 보고서는 `reports/README.md`에 색인한다. 작업의 정상 종료 조건은 **조사 내용과 검증/보류 기록의 저장까지**이다. 국가 `lifetime`·형상·타임라인 정본 적용, main 병합, 웹/앱 배포는 지시받지 않는 한 하지 않는다.

## 5. 초기 도입 검증 범위

이 문서는 **조사 순서와 보고 형식을 정한 운영 규칙**이다. CShapes 등의 특정 버전을 Pando 국경 형상과 대조하거나, SHP→GeoJSON 변환 품질·정확도·배포권한을 실제 검증했다는 뜻이 아니다. 매 조사에서 확보·검증한 자료만 그 회차 보고서에 명시한다.
