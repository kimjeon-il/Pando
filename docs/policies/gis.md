# GIS·역사 공간자료 정책

이 문서는 역사 국경·영토·행정구역·하천 경계·해안선·간척지·도서의 조사, 원본 선정과 복원의 정본이다. 원자료·연구·비 Viewer 제작 도구는 외부 PandoLab-library가 소유하고, Viewer와 공통 계산·자료 준비 계약은 이 저장소가 소유한다. 화면 자원과 동적 LOD는 [지도 표시 정책](map-rendering.md)을 따른다.

## 사건 선택과 표현 목표

- 국가 성립·소멸·분열·병합과 주요 영토 확장·축소를 우선한다. 선택한 사건의 실제 효력일과 귀속은 표현 축척과 별도로 확인한다.
- 일반적인 변화는 실제 달라진 **연결된 구역 약 500km² 이상**을 상세 조사·개별 복원 우선 기준으로 삼는다. 국가 전체 순증감이나 떨어진 필지의 합계로 판정하지 않는다. 미만의 변화, 작은 필지 교환·미세 경계 조정·퇴적·침식·하천 이동·계절 수위 변화는 원칙적으로 개별 정밀 복원에서 생략한다.
- 면적은 선별 참고값이다. 자동 수록·최소 가시 면적·위치 정확도·삭제 거리·고정 폭 기준이 아니다. 긴 띠의 폭·형상·대비·일반화 후 윤곽도 판단한다. 국가 존재, 주요 도시·중요 도서의 귀속, 중요한 통로·연결성을 설명하는 작은 예외는 이유를 기록하고 유지한다. 규모 미확정 사건을 임의로 작은 변화로 분류하지 않는다.
- 가용 자료로 사건을 선별한다. 생략 목록을 완성하거나 면적 기준 적용만을 위해 미세 사건 전체를 새로 측량·벡터화하지 않는다. 생략은 역사적 부재 판정이 아니다.
- 표시 파생본은 **Natural Earth 1:10,000,000(1:10M)** 수준으로 일반화한다. 이는 표현 복잡도와 작업 범위의 기준이며 일률적인 미터 오차, 정점 수, 좌표 자릿수나 삭제 거리가 아니다. 현대 Natural Earth 형상으로 과거 국경의 정확성을 입증하지 않는다.

## 원본 탐색과 역사적 근거

1. 선택한 사건의 장소·효력일에 맞는 SHP 구성 파일/ZIP, GeoPackage, GeoJSON, 공식 공간 서비스를 먼저 찾는다. 국가 기록원·공식 GIS·조약 부속도면·학술 자료의 범위·판본·제공기관·권리와 재배포 조건을 확인한다. 포맷만으로 정확도를 판단하지 않는다.
2. 측량·제작·발행·개정·데이터 유효연도와 조약 서명·발효·현장 이양·실효지배 날짜를 구별한다. 표지 연도나 지도 서비스 전체 연도 범위를 개별 지도의 기준일로 단정하지 않는다. 현대 행정구역을 근거 없이 과거에 소급하지 않는다.
3. 귀속과 일자는 독립적인 역사 지도·조약·공식/학술 문헌 **최소 두 출처**로 교차 검증한다. 같은 원본의 포맷 변환본이나 반복 비교는 독립 증거가 아니다. 벡터 미발견·미열람·접근 실패를 국경 부재로 해석하지 않는다.
4. 벡터가 없거나 부정확한 구간만 고지도 중첩·지오리퍼런싱·수작업으로 보완한다. 주요 노선과 귀속을 확인할 만큼 시대에 맞는 사료를 선택한다. 특정 상세 축척은 필수가 아니며, 더 세밀한 자료는 중요한 도시·도서·분기점 등 구체적인 쟁점이 있을 때만 추가한다.
5. CRS·레이어·ID·좌표 순서·폴리곤/멀티폴리곤·링·홀·섬·날짜변경선·공유 경계·유효기간과 선택한 주요 도서·월경지를 점검한다. SHP의 구성 파일·CRS·문자 인코딩 정보와 원본 해시를 함께 유지한다. 원본 CRS가 불명확하면 보류하며 임의의 CRS 지정으로 변환을 가장하지 않는다.

연도별 자동 조사 범위는 1801-01-01 이후 국가 성립·소멸·국제 지위 및 국가 간 국경·영토 변화다. 별도 해안 조사와 국가 존속기간 조사를 벡터 수집에 합치지 않는다. 이 범위는 새로운 자동 작업의 실행 지시가 아니다.

## 마스터 보존·일반화·검토 종료

- 실제 채택한 사건을 뒷받침하는 원본 사료·출처·지오메트리와 복원 마스터를 보존한다. 변환·일반화는 별도 파생본에서 수행한다. 재투영·반올림·날짜변경선 처리·합집합에 따른 변화와 지오리퍼런싱·판독의 불확실성을 기록한다. 변환 성공은 손실 없는 보존이나 역사 검증 완료를 뜻하지 않는다.
- 변화가 없다고 확인한 기준선은 재사용한다. 일반화에서 소국·중요 예외·필요한 도서·통로를 소멸시키지 않는다. 공유 경계는 일관되게 처리하고 단절·자기교차·중복·의도하지 않은 슬리버/구멍·틈/겹침을 방지한다. 단일 거리나 보존 비율만으로 적합성을 판정하지 않는다.
- 표시 파생본과 Natural Earth 1:10M 참조를 같은 투영·범위·배율에서 비교한다. 선택한 사건의 연대·귀속, 인식 가능한 형상과 필요한 위상이 뒷받침되면 종료한다. 증거가 부족한 구간은 `working`/`provisional`로 남긴다.
- 최대 확대는 기술 오류 확인의 보조 수단이다. 화면·DPR·줌 변경, 잔굴곡·서브픽셀 편차나 면적 기준만으로 추가 정밀 조사·수치 측정·완료 지역 재조사를 요구하지 않는다. 독립 기준선의 측정과 육안 검토를 구별한다. 기존 벡터를 일괄 삭제·자동 단순화하지 않으며 렌더러·메시 정확도 검사는 별도로 유지한다.
- 채택 사건에 기여하지 않는 상세 조사·중복본·종료된 일회성 도구는 [개발·운영 정책](development.md)의 보존·정리 기준을 따른다. 운영 원본과 유일한 근거를 불필요한 임시 출력과 함께 삭제하지 않는다.

## 해안·육지·수계·귀속

해안선·간척의 물리 변화, 내륙 수면, 수로 연결성, 영토 소유권은 독립된 사실이다. 국가 폴리곤 내부라는 이유로 마른 땅이라고 보거나, 건설·제방 폐쇄·배수·개통일을 토지 형성·귀속일로 대체하지 않는다. 점 포함 검사는 표본점만 설명하며 전체 형상·과거 해안 정확도를 입증하지 않는다.

변화 없는 해안은 재사용하고 선택한 주요 사건의 국소 전후 형상과 근거 있는 유효기간을 다룬다. 현대 GIS·원격탐사는 후보 발견에 쓸 수 있으나 독립된 시대 사료를 대신하지 않는다. 수면·해안·귀속은 같은 기준 시점으로 대조하고 불명확한 날짜는 추정으로 채우지 않는다. 미검증 변화가 원본·수계·국경을 자동 변경해서는 안 된다. 조사 방법·시범 설계는 제품의 구현·반영 완료를 뜻하지 않는다.

## 판단과 반영

| 상태 | 의미 |
| --- | --- |
| `source-indexed` | 원본·연도·서비스 후보만 파악 |
| `overlay-reviewed` | 중첩·육안 검토; 독립 수치 비교와 구별 |
| `screen-delta-checked` | 독립 기준선과 화면 위치 차이를 실제 측정 |
| `historically-verified` | 연대·귀속·필수 위상과 확인된 차이를 검증 |
| `provisional` | 근거·중요 예외가 미해결되어 최종 승격 보류 |

선택한 범위마다 적용 날짜, 원본의 측량·발행·개정 연도, 출처·권리·해시, 주요 경계 근거, 작업·생략 범위, 중요 예외, 일반화 방법, 참조 판본·비교 조건, 실제 검사와 미실행·미측정, 반영·보류 이유를 간결하게 남긴다. 생략 대상은 대략적 규모와 이유만으로 충분하다. 원본 미열람·변환 미실행·정량 미측정을 통과로 기록하거나 옛 관찰을 새 검증 결과로 바꾸지 않는다. 고유 연구 근거가 생기면 외부 라이브러리의 해당 보고서 범위에 보관하고 AGENTS.md의 보고서 완료 계약을 따른다.

권리·완전성 검토와 실제 반영 승인이 끝난 범위만 기존 객체 ID·형상 버전·시간 계약에 반영한다. 조사만으로 런타임 자료 핀·국가 존속기간·정본 형상·렌더러를 수정하거나 main 통합·배포하지 않는다. 관련 검사도 변경 범위에 한정하며 전체 GIS 검사를 자동 추가하지 않는다.
