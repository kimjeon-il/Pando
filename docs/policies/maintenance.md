# 정책 유지 관리

[중앙 색인](README.md)은 탐색만 소유하고 각 분야 파일은 그 분야 일반 정책의 정본이다. [AGENTS.md](../../AGENTS.md)의 에이전트 권한·보존·검증 제한과 실행 코드·기계 판독 계약을 중복 구현하지 않는다.

- 규칙을 추가·수정하기 전에 기존 소유자를 찾는다. 관련 일반 규칙은 같은 정본에서 갱신하며 별도 작업 설명서·단계 계획·실행 일지·완료 보고를 만들지 않는다.
- 특정 작업 문서에 유효한 일반 규칙이 있으면 현재 코드·확정 요구사항과 대조해 기존 정본에 통합하고 그 작업 문서·호출 참조를 제거한다. 과거 기록·수동 재현용이라는 이유로 보유하지 않는다.
- 날짜·작업 ID·특정 사례·당시 측정값·옛 버전·검사 실행 내역을 상시 정책으로 승격시키지 않는다. 고유 연구·원자료·평가 증거는 앱 설명서가 아닌 해당 외부 소유자와 명시적으로 승인된 범위를 따른다.
- 정책 의미는 실제 정본에서 바꾸고 다른 문서는 탐색 링크만 고친다. source·public URL·Worker·CI·외부 실제 소비자가 있는 경로를 이동하면 관련 호출자도 함께 전환한다. 호환 별칭·전달용 파일은 남기지 않는다.
- 실행 구성은 config·기계 판독 정책·등록 명령의 소유자가 담당한다. 일반 정책으로 위장한 특정 자료 SHA 요청이나 종료 작업 설정을 보유하지 않는다.
- 제3자 라이선스와 원문 출처 고지는 보존한다. 원자료·다른 작업·연결 대상은 문서 정리를 이유로 재귀 삭제하지 않는다.
- 변경한 정책·지침의 로컬 링크와 실제 소비자만 확인하고 [검증 정책](validation.md)에 따라 영향받은 동작을 검증한다. 검사 ID·단계별 목록을 문서마다 복제하거나 문서만 바꾸고 전체 제품·GIS 검사를 실행하지 않는다.

로컬 링크 확인은 코드의 동작, 외부 URL 도달성, 과거 검증의 진위나 GIS 정확성을 입증하지 않는다.
