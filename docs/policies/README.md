## 문서 효력 구분

**현행 규범**은 상위 [AGENTS.md](../../AGENTS.md)·[브랜치 정책](../branch-policy.md)과 분야별 원문에 있습니다. **실행 기준**은 해당 코드·스키마·구성 파일에서 확인합니다. **역사 자료**는 당시 계획·버전·검증 내용을 보존하며, 지금도 반드시 실행해야 할 명령이나 현재 통과된 검사로 해석하지 않습니다. **스테이징 정책**은 제품에 적용되었다는 근거가 필요합니다.

분야별 안내 페이지는 *탐색용*입니다. 여러 페이지에 나타나는 같은 문서도 정책 본문은 한 곳에만 존재합니다. 사용자 승인 없이는 정본·자료 핀·과거 증거를 이동하거나 의미를 바꾸지 않습니다.

## 정리 이력

- [P0 조사 당시 중앙 색인 전문](p0-overview.md) — 당시 확인된 12개 검토 항목 및 분류 근거
- [P0 구조화된 파일 목록](inventory.p0.json) — 조사 당시 **311개 경로** 기준선, 자동 재해석하지 않음
- [P1 중복 통합·구형 참조 결과](p1-reconciliation.md) — 실제 수정 내용과 보존 결정
- [P2 구조 정리·검증 범위](p2-maintenance.md) — 이후 점검과 유지 규칙

## 검증

`pnpm check:policies` 또는 `node scripts/check-policy-links.mjs`를 실행합니다. 정책 페이지·직접 링크된 원본 문서/코드/계약의 **상대 경로**, 분야별 검증 그룹 이름과 등록된 명령의 존재를 점검합니다. 실제 C++/WASM·브라우저 동작이나 외부 자료 정확도를 이 검사만으로 인증하지 않습니다.
