| [GIS·역사 자료](gis.md) | 국경 복원, 벡터 원본 검토, 해안선·지형 조사 |

## 정본과 유지 관리

현행 규범은 [AGENTS.md](../../AGENTS.md)와 분야별 정책이 소유하며, 브랜치·릴리스 운영은 [개발 정책](development.md)을 따른다. 문서와 실제 실행 코드가 다르면 현재 코드·확정 요구사항을 확인하고 기존 정본에서 바로잡는다. 별도 설명서나 병렬 정책으로 우회하지 않는다.

문서·경로 변경 후 영향받은 상대 링크와 현재 호출자를 확인하고, 제품 동작은 [검증 정책](validation.md)의 관련 시나리오로 확인한다.
