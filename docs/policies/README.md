# 판도연구소 정책·규칙 안내

현재 사용해야 하는 정책의 **위치·소유자·검증 계약**을 한곳에서 찾기 위한 입구입니다. 이 디렉터리는 정책 본문을 복제하지 않습니다. 원문 규칙·실행 코드·자료 핀·기계 판독 계약은 아래 연결된 원래 위치에서 계속 관리합니다.

| 분야 | 찾아볼 내용 |
| --- | --- |
| [개발·운영](development.md) | 상설 브랜치, 저장공간, 보고서, 앱 버전 및 배포 |
| [GIS·역사 자료](gis.md) | 국경 복원, 벡터 원본 검토, 해안선·지형 조사 |
| [지도 표시·LOD](map-rendering.md) | 지도 표시 순서, 벡터 LOD, 자원 무효화, 라벨 |
| [도시·지명](places.md) | 후보 선정·검수, 5등급 표시, 역사명·도시 라벨 기간 |
| [객체·시간축](objects-time.md) | 객체 신원·부모, 프로젝트 스키마, 타임라인 |
| [프로젝트·자료](data-projects.md) | 데이터 소유권, 기본 세계지도, 라이브러리 핀 |
| [UI](ui.md) | Viewer 공통 UI, 컴포넌트, 옛 편집 UI 구분 |
| [검증](validation.md) | 검증 계약, 명령, 변경 영향별 검사 |
| [정책 유지 관리](maintenance.md) | 현행화·링크·코드 소유자 점검 절차 |

## 정본과 유지 관리

현행 규범은 [AGENTS.md](../../AGENTS.md)·[브랜치 정책](../branch-policy.md)과 분야별 정본에 있다. 실행 기준은 해당 코드·구성·검사 계약에서 확인한다. 분야별 페이지는 정본을 찾기 위한 색인이며 규칙을 중복 소유하지 않는다.

문서·경로 변경 후 `pnpm check:policies`로 상대 링크와 등록 검사 식별자를 확인한다. 이 검사만으로 브라우저·WASM 동작이나 GIS 자료 정확성을 인증하지 않는다.
