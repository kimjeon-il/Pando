# 도시·지명 정책

이 문서는 도시 후보·게시 승인·시대별 명칭·도시 라벨 유효기간·5단계 표시의 일반 정책 정본이다. 각 판단은 독립적이며 하나의 등급표로 합치지 않는다. 지도 UI에서는 **도시**, 지리 객체·내장 자료에서는 `Place`/`place`/`places`, 명칭은 `name`을 쓴다. `label`/`labels`는 글자 표시·충돌 배치·선택·문서 계약의 별도 개념이다.

## 후보와 게시 승인

- 외부 라이브러리의 후보 선정 코드가 소유하는 기존 포함·제외 기준을 유지한다. GeoNames P 분류 중 수도·1/2차 행정중심지 또는 인구 5만 이상 PPL을 후보로 삼고, 10만 이상 자동 검토 후보와 그 미만 검색 후보를 구별한다. 후보 선정은 역사 도시 정체나 게시 승인이 아니다.
- 대량 조사·검수·비 Viewer 제작 도구와 원자료는 외부 PandoLab-library가 소유한다. ID 중복, 실제 위치·도시 정체, 근거·권리, 명칭 효력일과 지역 공용어를 검토한다. GeoNames 현대 국가코드·인구·좌표·행정분류로 과거 귀속·도시 자격을 확정하지 않는다. 역사 도시가 현대 후보에서 누락되면 독립 사료로 발굴할 수 있다.
- 승인 목록에 명시된 도시와 승인된 범위만 런타임 타일·검색·표시 순위에 게시한다. 검수 미완료·잠정 도시나 자동 승격 금지 예외를 새 배치·등급·수도 여부만으로 게시하지 않는다. 실행 형식이 필요한 유효기간 제약을 집행하지 못하면 자동 승격하지 않는다.
- 외부 편집 정책 JSON의 staging 판본과 실제 게시 상태를 구별한다. 현재 효력은 이 브랜치의 자료 핀·승인 데이터·매니페스트와 실행 코드에서 확인한다. 조사 완료·저장·원격 push를 main 통합이나 공개 배포로 표현하지 않는다.

## 시대별 명칭과 언어

- 한 ID·시점의 대표 한국어·영어는 각각 최대 하나다. 원어는 당시 통치국·관할기관의 실제 공식 사용명을 근거로 하나를 선정하며, 검증된 다언어 지역은 최대 세 개를 보존할 수 있다. 중앙과 지역 공식 언어가 다르면 지역의 공적 사용을 확인한다. 미확인 이름은 채우지 않는다.
- 한국어·영어명은 선정 원어에 대응하는 동시대 명칭을 원칙으로 하고 근거 있는 외칭을 허용한다. 다른 시대 번역을 혼합하지 않는다. 통치권 변경은 재검토 사유이며 자동 개칭 조건이 아니다. 한국어 편집 규칙만 바뀌면 다른 언어 이름을 추론하여 바꾸지 않는다.
- 구어·별칭·낡은 로마자 표기·중복 외칭을 지도 대표명에 무제한 수록하지 않는다. 근거 있는 검색 별칭과 정식 복수 공용어 예외를 구별한다. 중국 대륙 중국어계 지명의 한국어 편집은 1912-01-01을 경계로 한자음에서 중국어 발음 기반 표기로 전환하며 실제 원어 개칭과 구별한다. 일본 지명은 한자음 별칭을 별도로 저장하지 않는다. 이 편집 규칙의 도시별 실행 적용은 승인 자료에서 확인한다.
- 연도만 확인한 `fromYear`와 정확한 `fromDate`를 보존한다. 증거 없이 1월 1일을 대입하거나 국가코드·주권 변경으로 이름 전환일을 추론하지 않는다. 역사명 근거가 없어 현행명만 쓰는 경우 `(현)` 안내를 보존한다.
- 검수 원어의 언어·문자·출처는 원자료에 보존한다. 실행용 `nameNative`는 대표명, `nameNativeExtras`는 추가 최대 두 개다. 시점별 대표명을 바꿀 때 추가명 전체도 명시하여 이전 시기 목록을 잘못 상속하지 않는다. 영어·추가 원어·이력은 검색·상세정보 자료에 유지한다.

## 지도 라벨 표시

- 한국어가 항상 기본이다. `원어명 병기 (8배부터)`는 기본 꺼짐이며, 8배 이상에서 선택했을 때 대표 원어 한 줄만 작은 보조 행으로 표시한다. 영어 토글·원어 단독 표시는 제공하지 않는다.
- 한국어 라벨을 먼저 배치한다. 원어가 다른 라벨·보조 행과 충돌하거나 화면 밖이면 원어 행만 생략하고 한국어는 유지한다. 실제 선택 행 크기로 점유 영역을 계산한다. 한국어와 대표 원어가 NFKC·대소문자·공백·`(현)` 접두어를 제외한 비교에서 같으면 병기를 생략하며 다른 공용어로 대체하지 않는다.
- [이름 정책](../../src/data/place-name-policy.js)이 시점별 한국어·대표 원어 후보를, [라벨 배치](../../src/rendering/label-layout.js)가 한국어 우선 충돌 결과를 소유한다. 환경설정은 `labels.place.showNativeNames` 하나로 관리하고 변경 시 라벨만 무효화한다. 언어 표시 설정과 관계없이 검색은 한국어·영어·원어를 조회하며 타일을 재요청하지 않는다.

## 도시 라벨 유효기간

도시 라벨 자격은 취락의 물리적 존재, 명칭, 행정지위, 표시 등급과 독립적이다. 오래된 이름이나 어촌·농촌 존재만으로 도시 시작일을 앞당기지 않으며, 도시 소멸을 이유로 역사 장소·유적·검색 원자료를 삭제하지 않는다.

검수는 검증 범위·상태와 0개 이상의 활성 기간으로 소멸·재건을 표현한다. 정확한 시작일·첫 비활성일과 연도만 알려진 경계를 구별하고, 연도 안의 날짜나 검증 범위 밖 결론은 미확정으로 남긴다. 증거 없음은 도시 부재 증거가 아니다. 실제 월별 표시 판정과 경계 해석의 정본은 [유효기간 코드](../../src/data/place-lifetime-policy.js)이며, 과거 스테이징의 3상태 설계를 현행 런타임에 구현됐다고 가정하지 않는다.

동일 장소의 개칭·연속 성장은 ID를 유지한다. 실제 중심지가 이동하면 기존·새 도시를 별도 ID로 두고 전임·후계 관계를 기록한다. 같은 장소의 소멸·재건은 근거가 있을 때 한 ID의 복수 기간으로 표현할 수 있다.

## 인구·공간 기반 5단계 표시

[표시 순위 코드](../../tools/build/place-display-rank.mjs)가 인구를 기준으로 주변 밀집을 감점하고 고립을 가점한다. 후보 선정·도시 정체 검수·승인 목록·도시 유효기간을 이 계산으로 바꾸지 않는다.

| 단계 | 인구 기본 기준 이상 | 최초 확대 배율 |
| --- | ---: | ---: |
| 1 | 1,000,000 | 1.0 |
| 2 | 500,000 | 1.4 |
| 3 | 200,000 | 2.0 |
| 4 | 100,000 | 3.0 |
| 5 | 50,000 | 5.0 |

인구 경계는 사용자 확인 기준이다. 거리 반경·공간 계수는 복원된 임시 보정값이며 과거 확정 산식이 아니다. 최종 등급은 로그 인구점수에 밀집·고립 점수를 가감한 결과이므로 인구 기본 등급에서 이동할 수 있다. 정확한 산식·계수는 코드의 단일 모델에서 유지한다. 주변 후보도 같은 포함 함수를 사용하되 0/미상 인구는 밀집 계산에서 제외한다. 승인된 5만 미만 행정중심지는 기본 인구 등급 `null`과 화면 5등급 하한을 구별하며 일반 소규모 취락을 자동 승인하지 않는다.

현대 GeoNames 인구는 도시권·행정구역 경계가 일치하지 않을 수 있고 과거 시점의 실측 인구가 아니다. 현행 순위는 시각적 순서의 잠정 대체이며, 역사 중요도에는 검수된 시기별 자료가 별도로 필요하다. 매니페스트의 계산 결과를 Worker와 라벨이 사용하며 다른 소유자에서 별도 등급을 재계산하지 않는다.

## 실행 계약과 검증

[지명 계약](../../src/document/place-contract.js)이 `builtin:place:<source>:<sourceId>` ID와 현행 PLAC v3 필드를, [코덱](../../src/data/place-codec.js)이 바이너리 처리를 소유한다. 과거 PLAC·독립 앱 계약을 복제해 병렬 구현하지 않는다.

[Worker 저장소](../../src/data/place-worker-store.js)와 [런타임](../../src/data/place-runtime.js)의 조회·검색·불변 결과를 프로젝트 편집 상태나 DOM에 전체 적재하지 않는다. 새 요청이 이전 결과를 대체하는 취소 경계와 타일·검색 행 해시 검증을 유지한다. 승인된 타일·검색·매니페스트는 같은 승인 범위에서 생성한다.

검증은 변경 레코드·직접 영향 출력·관련 계약과 실제 Viewer 검색/시점/라벨 동작에 한정한다. 현행 등록은 `package.json`과 `scripts/contracts/application-checks.json`에서 확인한다. 생성기 논리는 작은 합성 fixture로 확인하고, 단일 명칭·기간 수정에 전체 도시 자료 검사를 연결하지 않는다. 기대값은 검수 원본과 대조하며 검사 통과만을 위해 재생성하지 않는다.
