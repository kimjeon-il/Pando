This folder contains the Large Scale International Boundaries (LSIB) geospatial dataset. Specifically, the LSIB dataset is distributed in shapefile format (.shp) and is located in the "data" folder.  The LSIB will transition from a shapefile-based to geopackage release at a future date. The inclusion of geopackage in the “data” folder is for testing purposes only and the shapefile is still the authoritative version of the dataset.  In order to increase the usability of the LSIB dataset, several related files are also provided.  These include GIS application files, ArcGIS Pro Map Package (.ppkx) in the "apps" folder and a QGIS Project (.qgz) at the root of this folder.  Additionally, cartographic style files (.sld, .stylx, and .lyrx) are in the "styles" folder.  The intent is to help facilitate use of the LSIB data by providing specific cartographic examples of how to style the lines. More information about the styling is provided in the metadata of the LSIB dataset. These additional application and style files are beta releases provided on an as-is basis.

For more information, see the Department of State GeoData web application (https://geodata.state.gov) where additional data downloads, metadata, source documents, and reference implementations of the data and styling are available as OGC web services and delievered within a web mapping application.  Beyond the LSIB, the GeoData app also has information about the World Polygons datasets, which might be more useful for some users.
